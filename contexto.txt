# CONTEXTO DO PROJETO: CONFIGURADOR 3D DE UNIFORMES ESPORTIVOS

## 1. Visão Geral
Aplicação web interativa para configuração e customização em 3D de uniformes esportivos (camisas, calções e meiões). O usuário pode alterar cores em tempo real, aplicar escudos e logomarcas de patrocinadores, selecionar itens do kit, escolher planos/pacotes e solicitar orçamento com gravação direta no Supabase.

---

## 2. Stack Tecnológica
- **Framework Front-end**: Next.js 14+ (App Router)
- **Linguagem**: TypeScript
- **Estilização**: Tailwind CSS + Lucide React (ícones)
- **Renderização 3D**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Gerenciamento de Estado**: Zustand
- **Banco de Dados & Storage**: Supabase (PostgreSQL + Storage para upload de logos/escudos)
- **Hospedagem / CI-CD**: Vercel

---

│   ├── components/

│   │   │   └── ModelOptions.tsx     # Seleção de tipo de gola e mangas
│   │   ├── summary/
│   │   │   ├── KitSelector.tsx      # Checkboxes de peças do kit (Camisa, Calção, Meião)
│   │   │   ├── OrderSummary.tsx     # Resumo e botão "Adicionar ao Orçamento"

│   │   └── packages/

│   └── lib/
